# StatDatathon 2026

Материалы работы над дататоном: анализ состава домохозяйств и площади жилья на синтетических данных за 2021–2024 годы, презентации, документы и исходники слайдов.

## Содержимое

- `submission/` — все текущие презентации и PDF: `StatDatathon.pptx`, `StatDatathon.pdf`, `StatDatathon_промежуточный_отсев_3_слайда.pptx`.
- `analysis_households.py` — воспроизводимые расчёты на стандартной библиотеке Python.
- `households_summary.json` — результаты расчётов по четырём годам.
- `.build-slides/build.mjs` — исходник генерации трёх слайдов; остальные файлы в `.build-slides/` — сохранённые версии, изображения, журналы и отчёты проверки.
- `выступление на открытии.docx` — исходный документ мероприятия.
- `synthetic_microdata_2021-2024_20260921/d006/` и `d008/` — все восемь таблиц, которые использует анализ.
- `synthetic_microdata_2021-2024_20260921/documentation/` — документация форм и справочники.
- `data-guide.html`, `data-guide.Rmd`, `MANIFEST.csv` внутри папки данных — описание и перечень полного датасета.

Все исходные материалы сохранены без редактирования. Технические зависимости `node_modules` и временные `.chart-data*` не включены.

## Повторить расчёты

Из корня репозитория с установленным Python 3:

```powershell
python .\analysis_households.py
```

Дополнительные библиотеки не нужны. Скрипт заново записывает `households_summary.json`. Для этого достаточно уже включённых D006 и D008; скачивать полный датасет не требуется.

Результаты относятся к синтетической невзвешенной выборке и не являются оценками населения Казахстана. При анализе площади исключаются записи, в которых жилая площадь превышает общую.

Исходник слайдов сохранён из рабочей среды Codex. Он использует `@oai/artifact-tool`, инструменты проверки презентаций и абсолютные пути этой среды. Его наличие не означает, что сборка слайдов запустится в обычном Node.js без настройки зависимостей и путей; готовые презентации находятся в `submission/`.

## Полный датасет

Полный исходный пакет занимает 4,69 ГБ и содержит 236 синтетических таблиц. Он сохранён отдельным ZIP-архивом в [релизе `initial-archive`](https://github.com/vl444dimir/datathon/releases/tag/initial-archive), поскольку отдельные CSV превышают [ограничения обычного GitHub-репозитория](https://docs.github.com/en/repositories/working-with-files/managing-large-files/about-large-files-on-github).

В архиве сохранена папка `synthetic_microdata_2021-2024_20260921/` целиком. Распакуйте её в корень репозитория, если понадобятся другие формы. Они исключены из обычных коммитов через `.gitignore`, но остаются в архиве релиза.

В том же релизе находятся SHA-256 архива и перечень исходных файлов с размерами и контрольными суммами. Доступ к релизу требует доступа к закрытому репозиторию.
