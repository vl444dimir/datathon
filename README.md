# StatDatathon 2026

Материалы работы над дататоном: анализ состава домохозяйств и площади жилья на синтетических данных за 2021–2024 годы, презентации, документы и исходники слайдов.

## Веб-страница

Адаптивная страница исследования находится в `web/`. На ней можно выбрать год, сравнить общую и жилую площадь на человека, скачать презентацию и агрегированные показатели. Значения берутся из `households_summary.json`. Для 2021 года показатель домохозяйств с детьми обозначен как недоступный: в исходных данных нет года рождения.

Раздел «Где тесно» показывает карту и рейтинг областей по доле домохозяйств с общей площадью ниже выбранного порога на человека (по умолчанию 15 м²) с 95% доверительными интервалами Уилсона. Ниже — калькулятор целевой группы: по порогу, типу семьи (с детьми, 3+ детей, многодетные 4+), местности и региону он считает долю группы ниже порога, её размер в выборке, охват всех домохозяйств ниже порога и риск относительно остальных. Данные — `/data/regions.json`: число домохозяйств в разрезе региона, местности, числа детей и целой площади на человека. Коды регионов `TE` расшифрованы по двузначным кодам КАТО, так как справочника в документации нет; `K`: 1 — город, 2 — село.

Границы 20 регионов после реформы 2022 года (17 областей и 3 города) взяты из OpenStreetMap (© участники OpenStreetMap, ODbL 1.0) и сохранены как SVG-контуры в `web/src/kz-regions.json`, поэтому сборке сеть не нужна. Пересоздать файл: `node scripts/build-kz-map.mjs` (запрашивает Overpass API и Nominatim; регионы сопоставляются по кодам ISO 3166-2:KZ, совпадающим с кодами КАТО).

### Локальный запуск

Нужен Node.js 22.12 или новее. В PowerShell из корня репозитория, без прав администратора и перезагрузки:

```powershell
npm.cmd ci
npm.cmd run dev
```

Откройте `http://localhost:5173`. Проверка готовой сборки:

```powershell
npm.cmd run build
npm.cmd run preview
```

Сборка появляется в `dist/`, просмотр — на `http://localhost:4173`. Перед запуском и сборкой скрипт автоматически готовит публичную копию агрегатов и PDF. После повторного расчёта `analysis_households.py` перезапустите веб-сборку.

### Запуск на сервере

На сервере должны быть установлены Git, Docker и Docker Compose. В терминале Linux, под пользователем с доступом к Docker:

```bash
git clone --depth 1 https://github.com/vl444dimir/datathon.git
cd datathon
docker compose up -d --build --wait --wait-timeout 60
docker compose ps
curl -fsS http://127.0.0.1:8080/healthz
```

Страница доступна по HTTP на порту `8080` сервера; проверка `/healthz` возвращает `ok`. Контейнер перезапускается автоматически. Порт по умолчанию слушает все интерфейсы. Для подключения через уже установленный Nginx/Caddy и HTTPS скопируйте `.env.example` в `.env`, установите `WEB_BIND_ADDRESS=127.0.0.1` и направьте reverse proxy на `http://127.0.0.1:8080`. Домен и TLS настраиваются на сервере отдельно. Если порт занят, измените `WEB_PORT` в `.env`.

Обновление из корня серверного клона:

```bash
git pull --ff-only
docker compose up -d --build --wait --wait-timeout 60
```

Для остановки: `docker compose down`. Для просмотра журнала: `docker compose logs --tail=100 web`. В контейнер попадают только собранная страница, агрегаты и PDF. Полный датасет, документы и секреты исключены из контекста сборки; база данных для текущей страницы не требуется.

При изменении веб-части GitHub Actions автоматически проверяет сборку, запуск контейнера, доступность страницы и материалов. Публикация на сервер выполняется отдельно командами выше.

## Содержимое

- `submission/` — все текущие презентации и PDF: `StatDatathon.pptx`, `StatDatathon.pdf`, `StatDatathon_промежуточный_отсев_3_слайда.pptx`.
- `analysis_households.py` — воспроизводимые расчёты на стандартной библиотеке Python.
- `households_summary.json` — результаты расчётов по четырём годам.
- `.build-slides/build.mjs` — исходник генерации трёх слайдов; остальные файлы в `.build-slides/` — сохранённые версии, изображения, журналы и отчёты проверки.
- `выступление на открытии.docx` — исходный документ мероприятия.
- `synthetic_microdata_2021-2024_20260921/d006/` и `d008/` — все восемь таблиц, которые использует анализ.
- `synthetic_microdata_2021-2024_20260921/documentation/` — документация форм и справочники.
- `data-guide.html`, `data-guide.Rmd`, `MANIFEST.csv` внутри папки данных — описание и перечень полного датасета.

Все исходные материалы сохранены без редактирования. Технические зависимости `node_modules` и временные `.chart-data*` не включены.

## Повторить расчёты

Из корня репозитория с установленным Python 3:

```powershell
python .\analysis_households.py
```

Дополнительные библиотеки не нужны. Скрипт заново записывает `households_summary.json`. Для этого достаточно уже включённых D006 и D008; скачивать полный датасет не требуется.

Результаты относятся к синтетической невзвешенной выборке и не являются оценками населения Казахстана. При анализе площади исключаются записи, в которых жилая площадь превышает общую.

Исходник слайдов сохранён из рабочей среды Codex. Он использует `@oai/artifact-tool`, инструменты проверки презентаций и абсолютные пути этой среды. Его наличие не означает, что сборка слайдов запустится в обычном Node.js без настройки зависимостей и путей; готовые презентации находятся в `submission/`.

## Полный датасет

Полный исходный пакет занимает 4,69 ГБ и содержит 236 синтетических таблиц. Он сохранён отдельным ZIP-архивом в [релизе `initial-archive`](https://github.com/vl444dimir/datathon/releases/tag/initial-archive), поскольку отдельные CSV превышают [ограничения обычного GitHub-репозитория](https://docs.github.com/en/repositories/working-with-files/managing-large-files/about-large-files-on-github).

В архиве сохранена папка `synthetic_microdata_2021-2024_20260921/` целиком. ZIP разделён на небольшие части для устойчивой передачи; `dataset-parts.json` задаёт их порядок и контрольные суммы. Готовый `Download-Dataset.ps1` скачивает части и автоматически собирает исходный ZIP, проверяя SHA-256 каждой части и всего архива.

Из корня репозитория, с установленным GitHub CLI и входом в аккаунт с доступом к репозиторию:

```powershell
.\Download-Dataset.ps1
```

Архив появится в `.local-archive/`. Распакуйте его в корень репозитория, если понадобятся другие формы. Существующие файлы скрипт не перезаписывает. Полные исходные данные исключены из обычных коммитов через `.gitignore`, но сохранены в релизе.

В том же релизе находятся SHA-256 архива и перечень исходных файлов с размерами и контрольными суммами. Доступ к релизу требует доступа к закрытому репозиторию.
